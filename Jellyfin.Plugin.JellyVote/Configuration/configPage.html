About JellyVote

JellyVote lets your household vote before media is removed. Quorum adapts to active users. Client UI is injected into jellyfin-web; native TV apps are not supported in v1.

Plugin ID: d2cffc5c-a675-431a-add8-abb93d6aaf1f

Install repository:
https://raw.githubusercontent.com/ThuGie/jellyfin-plugin-jellyvote/main/manifest.json

Safety defaults: library-only deletion, admin approval for disk deletes, block while playing, audit log in the plugin data folder.
